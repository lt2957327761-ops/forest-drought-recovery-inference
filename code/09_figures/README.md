# Figure and Source Data renderers

The directory contains the active renderer set for manuscript Figs. 1–5 and Extended Data Figs. 1–5. `Fig3_Nature_final_v04.py` imports the retained v03 and v01 helpers; those helpers are active dependencies, not alternative outputs. The Source Data builders require the separately retained source-pack CSVs, while the frozen final workbooks are already distributed with the Zenodo data release. Most final display scripts require MATLAB R2024b; Fig. 3 uses Python/Matplotlib.
