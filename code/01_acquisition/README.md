# Optional upstream acquisition

These product-level definitions document the frozen acquisition route. They are not executed by any repository driver and no Earth Engine task was started while assembling this release. MOD44B and MERIT are representative batch templates; the archived project used repeated year/tile batches. SPEIbase v2.11 was read from the public `CSIC/SPEI/2_11` asset, but a standalone acquisition script was not retained; this gap is recorded rather than reconstructed. The separately deposited Zenodo data are the recommended starting point for reproduction.
