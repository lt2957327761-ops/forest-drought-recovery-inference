# Software version 1.1.0 release notes

This author-approved release adds frozen evidence support and portable artifact verification for the current study. The baseline remains tag v1.0.0, commit 31dd78e93192e62ca359f4a8a3531f2ce0e073af; its old Version DOI is not reused for the new release.

Accepted strictly-before H−1 products, current figure/support inputs and Table S1 are supplied through the companion data archive. The verification program checks stored products without model loading/fitting, event recognition, ER/CI estimation or bootstrap. Current plotting inputs/helpers are supplied and statically checked; original figures are retained, not freshly rendered.

Original scientific code, model identities, fields, cohorts, environments and unsupported findings are preserved. Release-facing README/CITATION/CHANGELOG use version 1.1.0 and the current title with historical aliases. Exact new version DOI/date and code commit/tag are verified from actual release records; no values are inferred.

The tested reproduction tier is frozen-artifact reproduction, not a fresh end-to-end raw-to-paper run. Historical full-workspace dependencies and provenance-only raw-array/model routines remain explicit. See CHANGELOG.md and docs/EI_REPRODUCTION.md.
